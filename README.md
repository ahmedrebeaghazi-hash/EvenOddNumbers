🔢 Even or Odd Number Checker

Ein einfaches Programm zur Überprüfung, ob eine Zahl gerade oder ungerade ist.

📌 Projektbeschreibung

Dieses Projekt überprüft, ob eine eingegebene Zahl gerade oder ungerade ist. Es eignet sich für Anfänger, die grundlegende Programmierkonzepte kennenlernen und üben möchten.

🚀 Funktionen
Eingabe einer Zahl
Überprüfung, ob die Zahl gerade oder ungerade ist
Ausgabe des Ergebnisses
Einfache und verständliche Programmlogik
🛠️ Verwendete Technologien
Python
⚙️ Installation und Ausführung
Lade das Projekt herunter oder klone das Repository.
Stelle sicher, dass Python installiert ist.
Öffne das Terminal im Projektordner.
Führe das Programm mit folgendem Befehl aus:
bash
python even_odd.py

💡 Funktionsweise

Das Programm verwendet den Modulo-Operator %, um den Rest einer Division durch 2 zu berechnen.

Ist der Rest 0, ist die Zahl gerade.
Ist der Rest nicht 0, ist die Zahl ungerade.
