🔢 Even or Odd Number Checker
📌 Projektbeschreibung

Dieses Projekt ist ein einfaches C#-Programm, das überprüft, ob eine eingegebene Zahl gerade oder ungerade ist.

Es wurde entwickelt, um grundlegende Programmierkonzepte und die Verwendung von Bedingungen in C# praktisch zu üben.

🚀 Funktionen
Eingabe einer Zahl
Überprüfung, ob die Zahl gerade oder ungerade ist
Ausgabe des Ergebnisses in der Konsole
🛠️ Verwendete Technologien
C#
.NET
💡 Funktionsweise

Das Programm verwendet den Modulo-Operator %, um den Rest einer Division durch 2 zu berechnen.

Rest 0: Die Zahl ist gerade.
Rest ungleich 0: Die Zahl ist ungerade.
▶️ Ausführung

Voraussetzung ist ein installiertes .NET SDK.

Öffne das Projektverzeichnis im Terminal.
Führe folgenden Befehl aus:
bash
dotnet run
